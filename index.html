Comandos Linux que o professor pode pedir

Decodificar

echo 'c2VuaGE=' | base64 -d         # Base64
echo 'senha' | base64               # codificar
echo '73656e6861' | xxd -r -p       # Hex -> texto
echo 'frauen' | tr 'A-Za-z' 'N-ZA-Mn-za-m'   # ROT13
echo 'vhqkd' | tr 'd-za-c' 'a-z'    # César -3
echo -n 'senha123' | md5sum         # gerar MD5
echo -n 'x' | sha256sum             # gerar SHA-256
echo 'abc' | rev                    # inverter texto

Investigar páginas e arquivos

curl -s http://site/ | grep -i senha   # baixa HTML e filtra
curl -I http://site/                   # só cabeçalhos
wget -r http://site/                   # baixa o site todo
grep -rni 'senha' .                    # procura em pastas
strings arquivo | grep -i flag         # texto dentro de binário/imagem
file arquivo                           # descobre o tipo real
cat .arquivo_oculto ; ls -la           # arquivos com ponto
exiftool foto.jpg                      # metadados de imagem
find / -name '*flag*' 2>/dev/null      # caça por nome

Dicas: -n no echo evita a quebra de linha (muda o hash!). | passa a saída de um comando para o próximo. man comando ou comando --help mostram a ajuda na hora da prova. Se xxd não existir, use python3 -c "print(bytes.fromhex('73656e6861').decode())".

Roteiro para cada fase da prova

  1. Leia o enunciado inteiro: nome de cifra, palavra estranha, título da aba.
  2. Ctrl+U e Ctrl+F: senha, pass, user, <!--, flag.
  3. F12: Console, Elements, Sources, Application, Network (recarregue com F5 com a aba aberta).
  4. Achou algo cifrado? Identifique pela tabela e decodifique. Repita se ainda parecer cifrado.
  5. Olhe a URL: parâmetros como ?nivel=2 às vezes podem ser alterados à mão.
  6. Anote cada senha num bloco de notas. Uma fase pode reaproveitar senha anterior.

Fase de "adivinhar" credenciais

  • Do laboratório: aluno / aluno123, aluno / aluno, nome do lab, nome da sala.
  • Padrões: admin/admin, admin/123456, root/root, admin/password, user/user.
  • Contexto do professor: nome dele, da disciplina, da universidade, ano, com e sem @ e números.
  • Tela de bloqueio, papel colado no monitor, papel de parede, nome do computador: tudo é pista.
  • Teste variações de maiúscula e o ano atual (2026) no final.
